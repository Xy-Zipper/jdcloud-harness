# 造物片场用量费用写为已结算

[English](guide.md) | 中文

## 变更

造物片场媒体插件向低代码用量表 `6ad81c871f280486bb45ac5b` 写入已核算的客户费用时，将 `chargeStatus=ready` 改为 `chargeStatus=settled`，新增记录和恢复更新均适用。执行状态 `status` 保持原值；缺少用量或价格时仍为 `pending`，平台承担的调用仍为 `waived`。本地回执和工具消耗结果保留 `ready`。迁移保留既有已同步记录的执行和费用状态。

金额字段由 `customerChargeMicros/gatewayCostMicros` 改为 `customerCharge/gatewayCost`。金额直接保存为元／积分字符串，每次调用四舍五入到两位小数，例如 `320000` 微元变为 `"0.32"`。项目合计累加各次已取整金额；报价和工具消耗也返回两位小数。单价精度保持原值。读取历史本地回执时转换金额，不重新计价。

新用量记录和计费列表／同步响应由 `shadow` 改为 `metered`。历史回执保留原模式，包括旧 `shadow` 值。视频供应商任务编号继续保存于 `providerRequestId`，与本地 `requestId` 及业务任务关联 `taskId` 分开。恢复不再更新已结算记录；金额或供应商编号不一致时需人工核对。

## 迁移

1. 停止旧写入端，备份用量表、字段权限、关联查询投影及扣积分助手。历史金额除以1000000后四舍五入到两位小数，未知金额保持为空，迁移期间停用扣积分助手。
2. 同步更名表字段、权限、查询投影、前端、Skill（技能）及自动化中的两个金额字段。扣积分公式直接使用 `customerCharge`，不再除以1000000；保留每个助手原有的启用状态。
3. 同时部署更新后的前端、Skill 和 `@deepseek-ai/dsh-creation-studio-media` Host。新写入筛选接受 `settled`，历史报表同时接受 `ready/settled`。核对价格完整的调用写入小数金额且执行状态保持原值，并确认项目合计等于各次已取整金额之和。
4. 为用量表 `billingMode` 增加 `metered` 选项并设为默认值，保留历史 `shadow`。既有调用方需接受计费响应的 `mode=metered`。不要为了改模式而重写已结算记录，更新触发的数据助手可能再次扣分。核对新视频回执保留真实供应商任务编号，并确认恢复没有再次更新其已结算记录。
