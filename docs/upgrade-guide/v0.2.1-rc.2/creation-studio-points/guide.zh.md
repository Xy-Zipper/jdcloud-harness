# 造物片场新增付费调用前检查积分

[English](guide.md) | 中文

## 变更

媒体插件在新建项目、已绑定造物片场会话的每次模型请求，以及图片、视频或白底图新增付费提交前，读取团队空间表 `6adb0fbec3ca9f3dcdaf499a` 的 `points`。数值为0或负数时拒绝新增操作并提示充值，字段缺失、格式无效或不可读时也停止新增操作。已有任务查询和结果保存继续可用，不发起付费模型调用的记录更新也可继续。

## 迁移

1. 让项目创建者可读取当前团队空间的 `points` 字段。字段继续使用十进制文本，正数小数即可放行。已有空间通过既有管理员或充值流程配置积分。
2. 部署包含造物片场媒体插件的新版 Harness 和新版造物片场前端。
3. 确认零积分空间显示充值提示且没有创建项目或发起新的供应商请求；已有付费任务仍应能查询并保存结果。通过既有流程增加正数积分后重试，确认新增操作读取了新余额。

此校验只读取积分，不扣减或预留积分。
