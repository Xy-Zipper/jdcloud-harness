# 造物片场由 Seedance 输出复刻成片

[English](guide.md) | 中文

## 变更

新的 `video/tasks` 原片编辑请求会将整段原片交给方舟，包括过去只发送选中片段的 `redoSelected` 任务。模型处理画面、声音和字幕。所选时间段用于指导生成，模型限制和报价按原片时长计算。入库使用模型返回的 MP4，剪辑和混音可能与原片有差异。上传的 BGM 须为 MP3 或 WAV，大小不超过 15 MB，Seedance 2.5 支持 2–30 秒，2.0 系列支持 2–15 秒。已有回执仍可能关联 M4A 或时长超出上限的文件。

## 迁移

1. 同步部署造物片场前端和 Harness，为原片编辑启用所选模型的方舟视频账号。保留 `CREATION_STUDIO_VIDEO_REMAKE_WORKER_URL` 给原片拆解和带本地合成计划的回执恢复使用。
2. 提交新复刻前，在 BGM 面板更换格式或时长不符合要求的配乐。确认仅编辑所选镜头时，确认弹窗按整段原片估算。已经提交的任务使用原请求编号刷新，继续原成片入库。
