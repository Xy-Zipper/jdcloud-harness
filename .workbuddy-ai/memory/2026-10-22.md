## 修复容器启动报 corepack `UND_ERR_CONNECT_TIMEOUT`（拉 pnpm/latest 超时）

**根因链**：
1. Dockerfile runtime 层 `corepack prepare` 以 root 执行，缓存落在 `/root/.cache/node/corepack`；容器以 `USER node` 运行，缓存等于空。
2. 入口脚本在 `/workspace`（无 package.json/packageManager）下经 plugin-manager 调 `pnpm`，corepack 找不到版本声明 → 每次**启动**都去 registry 拉 `pnpm/latest` → 网络不通即崩。

**修复**（Dockerfile）：
- 构建期 `npm install -g pnpm@11.7.0`（builder+runtime），运行时用真实 pnpm 二进制，彻底绕开 corepack。
- 新增 `ARG NPM_REGISTRY`（默认 npmjs），可 `--build-arg NPM_REGISTRY=https://registry.npmmirror.com` 切镜像源；runtime 给 `/home/node/.npmrc` 写入同源 registry。
- **坑**：pnpm 11 不读 `npm_config_registry` 环境变量（本机已验证 env 不生效），必须用 `--registry` 参数或 .npmrc。
- 移除 `# syntax=docker/dockerfile:1`：该指令让 BuildKit 每次构建从 Docker Hub 拉前端镜像，受限网络下直接卡死（也是之前 `frontend grpc server closed unexpectedly` 的原因）。本文件未用到需前端的新特性。

**构建性能**：`.dockerignore` 漏了根目录 `jdcloud-harness.tar`（docker save 导出，数 GB），构建上下文 1.26MB → 6.87GB；已加 `jdcloud-harness.tar` 与 `.workbuddy-ai` 排除。

**不用重建的临时解法**：给现有容器加 `-e COREPACK_NPM_REGISTRY=https://registry.npmmirror.com`。

## 镜像交付从 `docker load -i tar` 扩展为 registry pull（方案已回滚，仅记录结论）

**状态**：用户当时尚未决定仓库方案，要求撤回代码改动。`compose.yaml` / `Docker.README.md` 已还原，`compose.build.yaml`、`docker-release.ps1` 已删除。下面仅作调研结论保留，**仓库中不存在这些改动**，不要再假设 `JDCLOUD_HARNESS_IMAGE` 存在。

**动机**：用户每次本地 `docker save` → `scp` → `docker load`，全量传输数 GB；希望改成 `docker pull` 增量更新。

**改动**（已回滚，见上方状态说明）：
- `compose.yaml` 拆成运行时文件：删掉 `build:`，`image: ${JDCLOUD_HARNESS_IMAGE:-jdcloud-harness:local}`。
- 新增 `compose.build.yaml` 覆盖文件承载 `build:`（含必填 `DSH_CLIENT_COMMIT_HASH`）。
  **原因**：`${DSH_CLIENT_COMMIT_HASH:?...}` 在解析期就插值，服务器 `.env` 没有该变量时 `docker compose up --no-build` 直接报 `required variable ... is missing a value`（已用 `docker compose config` 实测）。
- 新增 `docker-release.ps1`：取 commit → tag `<日期>-<短sha>` → `compose build`（带覆盖文件）→ push，可 `-Tar` 同时导出离线包、`-SkipPush` 只构建。
- 重写 `Docker.README.md`：三种交付方式对照（ACR pull / 内网自建 registry / tar），含服务器出网自检 `curl .../v2/`（401=可达）。

**结论性判断**：`docker pull` 必须有到 registry 的网络。纯内网服务器只有两条路——服务器自建 `registry:2`（绑 127.0.0.1，本地 SSH 隧道 push，pull 走回环，仍只传增量层），或继续 tar。阿里云 ACR 个人版免费（3 命名空间 / 300 仓库 / 拉取 QPS 不保障 / 2024-09 后无免密拉取 / 绑单地域），但公网域名要求服务器出网。
